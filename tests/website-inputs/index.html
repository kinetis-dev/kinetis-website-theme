Everything your application needs, out of the box

Typed requests, zero boilerplate

Define a route with a PHP attribute. A malformed request comes back a 422 with every field error at once, before your controller code ever runs.

OpenAPI that's never out of date

A full OpenAPI 3.1 spec and Swagger UI, generated straight from your route attributes. Nothing to hand-write, nothing to fall out of sync.

Real concurrency, not an illusion

Run several database queries, an HTTP call, and a cache read side by side and wait once, all on plain PHP Fibers with no extra processes.

Non-blocking, top to bottom

A slow database query or a flaky third-party API suspends a Fiber, not the whole worker, so one slow request never stalls the ones behind it.

A native AI agent interface

A Model Context Protocol server ships with the framework. Install it, and your API's tools and resources are callable by any MCP-compatible agent.

Authentication and authorization included

Bearer tokens or JWT, password hashing and token revocation, an unopinionated authorization layer, plus sessions, CSRF, and rate limiting.

Background jobs, any backend

Queues on Redis, SQL, Amazon SQS, or RabbitMQ, with retries, delays, priorities, and graceful shutdown behind one interface.

Storage, mail, and search

File storage on local disk or S3, transactional email, and OpenSearch, all built on the same non-blocking core as everything else.

Deploy anywhere, same code

Runs unchanged on classic PHP-FPM, a FrankenPHP or RoadRunner persistent worker, or AWS Lambda. Start simple, move to a worker when it suits you.
